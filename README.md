# Monster Mulching

Astro site for [monstermulching.nz](https://monstermulching.nz).

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # output in dist/
```

Pages live in `src/pages/`, contact details in `src/data/business.ts`. Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
